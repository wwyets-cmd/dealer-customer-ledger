# 每周订单数据导入教程（回单记录）

> 代理商每周把销售/订单明细导入一次，代理自动分析识别后写入「回单记录」表，一次几十到几百行均适用。
> **核心原则：不绑定任何一家公司的 ERP 或导出格式。** 不同代理商系统不同、列名千差万别，一律按表头**核心字样模糊识别**列，再做归一；识别不准或有歧义的列，当场向使用者确认，不猜。

## 一、必需信息（无论列名叫什么，识别到即可）

| 目标字段 | 表头核心字样（命中任一即可，忽略空格/括号/单位后缀） |
| --- | --- |
| 订单日期 | 订单日期、下单日期、开单日期、订货日期、销售日期、业务日期、日期 |
| 客户名 | 客户名称、客户简称、客户、购货单位、经销商、收货单位、客户公司、往来单位、购买方 |
| 产品 | 物料描述、产品名称、商品名称、品名、货物名称、货品名称、物料名称、产品、规格型号 |
| 数量 | 数量、销售数量、发货数量、出货数量、数 量（**优先"数量"**；"件数/箱数"仅在无数量列时用） |
| 单价 | 单价、含税单价、销售单价、成交价、单价（元）（无单价列可由 金额÷数量 反算并备注） |
| 总金额 | 含税金额、价税合计、总金额、金额、销售额、销售金额、成交金额、总价、含税本位币金额 |

可选字段：业务员（销售员/业务员/销售人员/业务/经手人/跟进人）、单位（单位/计量单位：套/PCS/支/个/箱/副）、订单号（订单编号/订单号/销货单号/单号/单据编号）、规格型号/物料编码、备注。

**日期口径统一按「订单日期」**（客户下单/开单日）。若该表只有发货/出库/交货日期而没有订单日期，则退而用该日期，并在导入回执里注明"本表按发货日期归集"。

## 二、文件与表头识别（自动执行）

1. **格式兼容**：支持 `.xlsx` / `.xls` / `.csv` / 表格截图。注意很多 ERP 导出的 `.xls` 实际是 **HTML 伪装表格**（pandas 直接读会报 format 错误），需改用 HTML 表格方式解析；CSV 注意 UTF-8/GBK 编码。
2. **定位表头行**：ERP 导出常有标题、日期范围、筛选条件等前导行，表头不一定在第 1 行。自动扫描前若干行，把**同时出现"客户/产品(品名)/数量/金额"等多个关键词的那一行**识别为表头行，其下才是数据。
3. **列映射**：按第一节关键词把每一列映射到目标字段；同一目标命中多列时按优先级取（如金额优先"含税金额/价税合计"）；**必需字段缺列或一列对不上多个含义时，先问使用者再导**。
4. **日期解析**：兼容 `2026/9/4`、`2026-09-04`、`2026.9.4`、`2026年9月4日` 等，统一转 `YYYY-MM-DD HH:mm:ss`；无法解析的日期列出问。

## 三、退货行识别（金额自动净额）

满足任一条件即判定为**退货/红冲行**：
- 数量或总金额为**负数**；
- 单据类型/订单类型/销售类型列含"退、退货、红冲"；
- 单号前缀或备注明确是退货单。

处理：**保留负号原样导入**（数量、总金额为负），不得改成正数、不得丢弃。这样「回单记录」写入后，客户名单的「整体回单金额」用 SUM 自动**销货−退货净额**，业绩真实。可在"凭证/备注"自然注明"退货"，但不强制。

## 四、产品与客户归一

1. **产品归一**：产品名/物料描述按 references/product-catalog.md（276 个型号系列）+ references/vocab-errors.md 归到"业务大类 + 规范系列"（如"拉篮-天蝎N810""升降机-星移SL-S""基础五金-铰链YH2"）；尺寸/颜色/弯别（W800、-300、直臂/中弯、拉丝/枪灰）作规格保留，不另建型号；识别不出或拿不准的行先问，不乱写。
2. **客户匹配**：按 SKILL 核心工作流第 3 步的**名称归一化 + 核心字号模糊匹配**对客户名单查重：唯一命中→挂该客户；多候选→列候选让使用者选；无命中→先建档（客户性质=存量客户，负责业务员=该行业务员或录入人）再挂关联。
3. **业务员**：有业务员列直接用；没有则按客户名单「负责业务员」匹配。

## 五、数字复核与去重

1. **守恒校验**：逐行核对 `数量 × 单价` 与总金额，差异 >1 元或 >1%（折扣/运费等）时以表中**实际总金额为准**并在备注说明。
2. **关键数字回读**：数量、单价、总金额、负数退货为高错误成本项，导入前向使用者回读汇总确认。
3. **重复导入防护**：一周一导。若同一文件/同一批单疑似重复导入，按"订单号 + 客户 + 产品 + 日期 + 金额"判重，发现已存在的行先提示，不重复写入。

## 六、写入流程（WorkBuddy 版 / 飞书连接器）

- 通过「飞书」连接器的多维表格**批量新建记录**能力写入「回单记录」表。
- 字段：客户名称(主字段,文本)、产品(文本)、数量(number)、单价（元）(number)、总金额（元）(number，退货为负)、订单日期(datetime，`YYYY-MM-DD HH:mm:ss`)、业务员(text)、关联客户(link，关联记录 id)、凭证/备注(text)。
- 只写存储字段；auto_number / formula / created_at 等只读字段不写。批量后检查是否多产生主字段为空的记录，有则删除。

## 七、导入后校验（必须）

1. 通过连接器重新查询本批记录：导入条数 = Excel 有效数据行数（含退货负数行）。
2. 金额合计校验：本批**净额合计** ≈ Excel 销货−退货合计（差 >1 元查明原因）；单独报出退货笔数与退货金额。
3. 回执给使用者：导入 N 条（销货 X / 退货 Y）、涉及 M 个客户、净额合计、按订单日期归集的说明、以及未识别清单（产品存疑、客户未匹配、日期无法解析的行），确认后才算完成。

## 八、常见问题

- **客户简称对不上名单全称**：按核心字号匹配，仍不确定就列候选问，不建重复客户。
- **产品不在词库**：先问归到哪个品类/系列，确认后再写；不猜测。
- **一列里混了多个含义 / 表头合并单元格**：请使用者指出该列含义，或让其重新导出规范表。
- **金额是文本带货币符号或千分位**（¥1,200.00）：去符号和逗号转数字；转不出则问。
