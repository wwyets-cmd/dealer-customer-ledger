# WorkBuddy 安装与配置教程（dealer-customer-ledger）

本教程面向在 **WorkBuddy（OpenClaw 生态）** 上使用台账技能的代理商。共 4 步，约 5 分钟。

---

## 第 1 步：安装技能

1. 从 GitHub 仓库下载：`https://github.com/wwyets-cmd/dealer-customer-ledger`
2. 找到仓库内 **`workbuddy/dealer-customer-ledger`** 文件夹（注意：不是仓库根目录那版，那是豆包版）。
3. 把整个 `dealer-customer-ledger` 文件夹放入 OpenClaw 技能目录：
   - 默认路径：`~/.openclaw/workspace/skills/dealer-customer-ledger/`
   - 或在 WorkBuddy 客户端「专家·技能·连接器」→「技能」页，使用导入入口选择该文件夹。
4. **新开一个对话**（或按客户端提示重载技能），让技能被加载。

> 技能文件结构：`SKILL.md` + `references/`（install-workbuddy / entry-template / import-guide / base-schema / vocab-errors）。

---

## 第 2 步：配置飞书连接器（关键）

台账数据写在飞书多维表格里，必须先连接飞书。

1. 打开 WorkBuddy 左侧「**专家·技能·连接器**」→ 顶部选「**连接器**」页。
2. 找到「**飞书**」卡片（说明为"管理飞书/Lark：即时通讯、云文档、电子表格、多维表格 Base…"），点右上角「**+**」。
3. 按弹出的指南完成授权，常见为两种方式（以实际引导为准）：
   - **快捷授权**：直接扫码 / 登录飞书账号，勾选同意多维表格权限；
   - **应用凭证**：到飞书开放平台创建一个「飞书智能体 / 自建应用」，拿到 **App ID、App Secret** 回填，并在「权限管理」开通多维表格权限，至少包含：
     - 查看、评论、编辑和管理多维表格（`bitable:app`）
     - 多维表格记录创建 / 读取 / 更新（如 `base:record:create` 等）
4. 授权完成后，飞书卡片显示已连接（绿点）。

> 权限务必开全，否则会出现"能读不能写"或无法新建记录。

---

## 第 3 步：复制自己的台账模板

每位代理商 / 每个门店**复制一份自己的副本**，不要在公共母版上录数据。

1. 用自己的飞书账号打开模板：
   `https://my.feishu.cn/base/FyKib8lh8aIqJxsHppUcVkDnnEb`
   （打不开 / 没权限，找管理员开「可编辑」或「可复制」权限）
2. 点左上角**表格名旁的「⋯」**（手机端在右上角「⋯」，或在飞书云空间右键该文件）。
3. 选「**复制**」→ 选保存位置（建议"我的空间"）→ 命名，如 `客户台账-姓名`。
4. 打开副本确认含 **5 张表 + 看板**：
   - 客户名单、拜访记录、回单记录、竞品信息收集、上样登记表 + 信息汇总看板。

---

## 第 4 步：在对话里确认信息，开始录入

1. 在 WorkBuddy 新对话里告诉助手：
   - **录入人 / 业务员姓名**（如"我是王磊"）；
   - **你复制的台账副本链接**。
2. 助手回读确认后，即可开始语音 / 文字录入，例如：
   > "录一下今天拜访的：济南华鑫全屋定制，老客户，轻高定……"
3. 每次录入后助手会：回写各表 → 回读核对 → 给出一段可直接发工作群的汇报文案。

---

## 常见问题

- **连接器里找不到飞书**：更新 WorkBuddy 到最新版；或用「自定义连接器」按官方飞书指南添加。
- **提示无权限 / 写入失败**：回第 2 步检查多维表格权限是否开全；并确认你对台账副本有「可编辑」权限。
- **技能没出现**：确认文件夹放在正确的 skills 目录、且内含 `SKILL.md`，然后新开会话重载。
- **换电脑**：技能与连接器配置随账号 / 工作区同步，重新登录后按第 1–2 步核对即可。
