# 模板复制教程（代理商操作，照着做即可）

> 每位代理商复制一份自己的多维表格副本，之后所有录入都写进自己这份副本，互不干扰。模板本身是"母版"，**不要在模板上直接录数据**。

## 一、准备

1. 拿到模板链接：https://my.feishu.cn/base/FyKib8lh8aIqJxsHppUcVkDnnEb
2. 用**自己的飞书账号**登录（没有账号先注册飞书）。
3. 如果打开提示"无访问权限 / 只读"：请联系管理员把模板分享给你，权限设为**可编辑**，否则无法复制。

## 二、复制步骤

1. 打开模板链接，进入多维表格。
2. 点左上角**表格名称旁的「⋯」更多菜单**（或在自己的飞书云空间文件列表里找到这个表格，点右侧「⋯」）。
3. 选择**「复制」**。
4. 选择复制位置（建议选"我的空间"），并给副本命名，例如：`客户台账-王磊`。
5. 点确定，系统生成副本并自动打开。

## 三、复制后检查

1. 确认副本里有 **5 张表**：客户名单 / 拜访记录 / 月度采购 / 竞品信息收集 / 上样登记表。
2. 确认有**看板**（信息汇总看板）。
3. 检查无误后，**复制浏览器地址栏里这个副本的链接**。

## 四、告诉豆包

1. 把副本链接发给豆包（技能安装流程里的"确认 Base"步骤）。
2. 报你的姓名（录入人）。
3. 确认后即可开始语音录入，所有数据写入你自己的副本。

## 常见问题

| 问题 | 解决 |
|---|---|
| 打开模板没权限 | 找管理员开「可编辑」权限 |
| 找不到「复制」按钮 | 手机端在页面右上角「⋯」；电脑端在表格名旁「⋯」或云空间文件列表右键 |
| 复制后没有看板 | 个别版本复制不含看板，告知豆包，豆包引导重建 |
| 已经录错了想重新开始 | 重新复制一份模板即可，旧副本留着不影响 |
