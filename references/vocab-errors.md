# 词库与口音纠错（Vocabulary & Accent Correction）

> 使用者多为语音录入，方言/口音会造成同音字、近音词识别错误。解析语音时先按本词库匹配，再落字段。拿不准的词主动复述确认，不要猜。

## 强制纠错规则（用户明确确认）

| 语音说 | 统一录入 | 说明 |
|---|---|---|
| DTC / 帝腾 / 迪腾 / 类似音 | 东泰 | 东泰和 DTC 是一家，一律录「东泰」 |
| 脚链 / 角链 / 交链 | 铰链 | 脚链→铰链 |
| 轻搞定 / 轻高顶 | 轻高定 | 客户类型选项之一 |
| 拉栏 / 拉蓝 | 拉篮 | 产品名 |
| 水槽 / 水曹 | 水槽 | 产品名 |
| 滑跪 / 滑柜 | 滑轨 | 产品名 |
| 反弹器 / 反弹气 | 反弹器 | 产品名 |

## 识别策略

1. 优先整词匹配词库（品牌/产品/城市），命中即采用，不受同音字干扰
2. 型号类（如 SL-A、OT 重型、HIG-560、PW-220）保留英文/数字原样，中文部分按产品词库归一
3. 客户名称以客户名单已有记录优先；疑似新客户时向使用者确认全称
4. 电话、地址、金额这类高错误成本信息，录入前向使用者复述一遍确认
