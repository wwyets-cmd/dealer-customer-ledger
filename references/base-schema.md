# 多维表格结构（Base Schema）

> 本文档描述代理商客户拜访与开发台账的 5 张表结构与录入映射。所有写入前先 `+table-list` / `+field-list` 回读真实表 id 和字段名，禁止凭记忆猜字段。

## 表清单（默认模板 base）

| 表 | 用途 | 关键字段 |
|---|---|---|
| 客户名单 | 客户主档 | 客户名称（主字段）、客户性质、客户类型、老板/联系人、门店地址、联系电话、开发阶段、负责业务员 |
| 拜访记录 | 每次拜访 | 客户名称、拜访日期、拜访业务员、本次目的、本次结果、对接内容、下次跟进事项、下次跟进日期 |
| 月度采购 | 每月采购 | 客户名称、月份、销售额（含税元）、退货额、采购净额（公式=销售额-退货额） |
| 竞品信息收集 | 竞品情报 | 客户名称、竞品品牌、竞品型号、价格（元）、客户采购量 |
| 上样登记表 | 上样照片登记 | 公司名称、序号（自动编号）、门店/工厂、联系人、电话、地址、门头签单合照、协议合照、上样前照片、上样后照片、备注上样产品、上样日期、关联客户 |

## 跨表关联

- 拜访记录.关联客户 → 客户名单
- 月度采购.关联客户 → 客户名单
- 竞品信息收集.关联客户 → 客户名单
- 上样登记表.关联客户 → 客户名单
- 客户名单反向字段：拜访记录、月度采购、竞品信息、上样登记

写入关联字段用 `[{ "id": "<record_id>" }]`，先 `+record-list` 按客户名称查到 record_id。

## 录入映射（语音 → 字段）

| 用户说的 | 落到哪个表哪个字段 | 规则 |
|---|---|---|
| 客户名称 | 客户名单.客户名称 | 已存在→挂关联；不存在→先建档 |
| 新开发 / 老客户 | 客户名单.客户性质 | 新开发→开发阶段=待接触；老客户→持续补货（如有采购） |
| 客户类型（默认轻高定） | 客户名单.客户类型 | 选项：轻高定/设计工作室/普定门店/前店后厂/普定工厂/代工厂（板材） |
| 老板/联系人 + 门店 + 电话 | 客户名单.老板联系人/门店地址/联系电话 | 语音易错，可让用户确认 |
| 拜访内容 | 拜访记录.对接内容 | 本次主要对接了什么 |
| 下次动作 + 下次跟进日期 | 拜访记录.下次跟进事项/下次跟进日期 | 建议必报 |
| 竞品品牌/型号/价格/采购量 | 竞品信息收集 | 品牌按词库纠错 |
| 上样照片 | 上样登记表.4个照片字段 | 按内容分类；上样日期=照片水印时间 |

## 自动补全（不问用户）

- 拜访日期 / 执行日期 → 今天
- 拜访业务员 → 安装时确认的录入人
- 上样日期 → 照片水印相机时间（识别照片水印，不是默认今天）
- 序号 → 自动编号 NO.001…
- 采购净额 → 公式自动算

## 只读字段（不写）

auto_number（序号）、formula（采购净额、今日拜访标记）、created_at/updated_at。
