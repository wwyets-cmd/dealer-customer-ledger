# 多维表格结构（Base Schema）

> 本文档描述代理商客户拜访与开发台账的 5 张表结构与录入映射。**字段名、select 选项以本文档为准**；写入前仍建议先 `+table-list` / `+field-list` 回读真实表 id 和字段名，禁止猜字段。

## 客户名单（客户主档）

| 字段 | 类型 | 说明 |
|---|---|---|
| 客户名称 | text | 主字段 |
| 客户性质 | select | 新开客户 / 存量客户（语音"新开发/老客户"归一到此） |
| 客户类型 | select | 轻高定 / 设计工作室 / 普定门店 / 前店后厂 / 普定工厂 / 代工厂（板材） |
| 联系人 / 职务 | text | 语音"老板"归一到此 |
| 联系电话 | text | |
| 区县 | text | |
| 详细地址 | text | 语音"门店几楼/工厂地址"归一到此 |
| 开发阶段 | select | 初步接触 / 已明确需求 / 上样待确认 / 上样待首单 / 首单已确定 / 持续补货 / 明确拒绝 |
| 负责业务员 | text | 自动=录入人 |
| 首单日期 | datetime | |
| 上样完成日期 | datetime | |
| 首单净额（元） | number | |
| 上样 / 首单证据 | text | |
| 当前卡点 / 需协助 | text | 语音"卡点问题"归一到此 |
| 下一步具体动作 | text | |
| 下次跟进日期 | datetime | 语音"下次跟进日期"归一到此（注意：不在拜访记录表） |
| 拜访记录 / 月度采购 / 竞品信息 / 上样登记 | link | 反向关联字段（只读侧，不写） |
| 有效新增日期（自动） | formula | 只读，不写 |

## 拜访记录（每次拜访）

| 字段 | 类型 | 说明 |
|---|---|---|
| 客户名称 | text | |
| 拜访日期 | datetime | 自动=今天 |
| 执行日期 | datetime | 自动=今天 |
| 拜访业务员 | text | 自动=录入人 |
| 接触方式 | select | 实地拜访 / 电话回访 / 微信沟通 / 其他 |
| 本次目的 | select | 新客户开发 / 客情维护 / 新品推广 / 订单跟进 / 售后回访 / 货款催收 / 其他 |
| 本次结果 | select | 已成交 / 有意向 / 持续跟进 / 暂无需求 / 其他 / 明确拒绝 |
| 核实到的需求 / 决策人 | text | 语音"本次对接了什么"归一到此 |
| 下一步具体动作 | text | 语音"具体动作与方案"归一到此 |
| 证据 / 需协助 | text | |
| 关注品类 | text | |
| 现用品牌 / 产品 | text | |
| 关联客户 | link | → 客户名单，按客户名称匹配后写 record_id |
| 今日拜访标记 | formula | 只读，不写 |

> 注意：拜访记录表**没有**「下次跟进日期」字段；下次跟进日期写入**客户名单.下次跟进日期**。

| 字段 | 类型 |
|---|---|

| 电话 | text | |
| 地址 | text | |
| 门头签单合照 | attachment | 照片归档 |
| 协议合照 | attachment | |
| 上样前照片 | attachment | |
| 上样后照片 | attachment | |
| 备注上样产品 | text | |

| 关联客户 | link → 客户名单 | 老客户自动挂，新客户先建档 |

## 录入映射（语音 → 字段）

| 用户说的 | 落到哪个表哪个字段 |
|---|---|
| 客户名称 | 客户名单.客户名称；已存在→挂关联；不存在→先建档 |
| 新开发 / 老客户 | 客户名单.客户性质 = 新开客户 / 存量客户 |
| 开发阶段自动 | 新开客户→初步接触；存量客户→持续补货（如有采购） |
| 客户类型（默认轻高定） | 客户名单.客户类型 |
| 老板 | 客户名单.联系人 / 职务 |
| 门店几楼 / 地址 | 客户名单.区县 + 详细地址 |
| 电话 | 客户名单.联系电话 |
| 本次对接内容 | 拜访记录.核实到的需求 / 决策人 |
| 卡点问题 | 客户名单.当前卡点 / 需协助 |
| 具体动作与方案 | 拜访记录.下一步具体动作 |
| 下次跟进日期 | 客户名单.下次跟进日期 |
| 竞品 | 竞品信息收集（品牌/型号/价格/采购量） |
| 采购 | 月度采购（采购月份/销售额/退货额） |
| 上样照片 | 上样登记表（4 照片字段 + 上样日期=水印时间） |

## 只读字段（不写）

auto_number（序号）、formula（采购净额、今日拜访标记、有效新增日期）、created_at / updated_at、link 反向字段。
