# 多维表格结构（Base Schema）

> 本文档描述代理商客户拜访与开发台账的 5 张表结构与录入映射。**字段名、select 选项以本文档为准**；写入前仍建议先 `+table-list` / `+field-list` 回读真实表 id 和字段名，禁止猜字段。

## 客户名单（客户主档）

| 字段 | 类型 | 说明 |
|---|---|---|
| 客户名称 | text | 主字段 |
| 客户性质 | select | 新开客户 / 存量客户（语音"新开发/老客户"归一到此） |
| 客户类型 | select | 轻高定 / 设计工作室 / 普定门店 / 前店后厂 / 普定工厂 / 代工厂（板材） |
| 联系人 / 职务 | text | 语音"老板"归一到此 |
| 联系电话 | text | |
| 区县 | text | |
| 详细地址 | text | 语音"门店几楼/工厂地址"归一到此 |
| 开发阶段 | select | 初步接触 / 已明确需求 / 上样待确认 / 上样待首单 / 首单已确定 / 持续补货 / 明确拒绝 |
| 负责业务员 | text | **默认首建人固定，可手动转交**：新建客户=录入人（首建人）；之后其他业务员再拜访，本字段**保持首建人不变**（拜访记录.拜访业务员始终记实际拜访人）；仅当使用者明确说"把 XX 客户转给 XX"时才更新本字段并回读确认 |
| 现用产品 | text | 客户目前主要用的产品 |
| 品牌 | text | 客户目前在用的品牌 |
| 合作供应商（竞争对手） | text | 客户目前合作的供应商/竞对 |
| 意向产品/需求 | text | 语音"意向产品、需求"归一到此 |
| 是否上样 | formula | 联动上样登记表：有上样记录=是，否则=否（只读，不写） |
| 整体回单金额 | formula | 联动回单记录：按客户统计全部订单总金额合计（只读，不写） |
| 客户拜访次数 | formula | 联动拜访明细：该客户关联的拜访记录条数（只读，不写） |
| 拜访频率（次/月） | formula | 总拜访次数 ÷ 首次拜访至今的自然月数（含首月），保留1位小数（只读，不写） |
| 最近拜访日期 | formula | 联动拜访明细：=最近一次拜访的日期 MAX([拜访明细].[拜访日期])；无拜访=空（只读，不写） |
| 当前卡点 / 需协助 | text | 语音"卡点问题"归一到此 |
| 下次跟进日期 | datetime | 语音"下次跟进日期"归一到此（注意：不在拜访记录表） |
| 回单明细 / 拜访明细 / 竞品信息 / 上样登记 | link | 反向关联字段，固定排在表格**最后四列**（只读侧，不写）。**注意命名：反向 link 字段名不得与目标表同名**——拜访记录/回单记录两张表的反向字段特意命名为「拜访明细」「回单明细」，否则公式里 `[拜访记录]` 会被解析成"整张表"而非"本列关联"，导致 COUNTA/SUM 统计为空 |

> 公式引用口径：客户名单所有联动统计均通过反向 link 字段（拜访明细/回单明细/上样登记）取值，如 `COUNTA([拜访明细])`、`MAX([拜访明细].[拜访日期])`、`SUM([回单明细].[总金额（元）])`；禁止在公式里写与表同名的 `[拜访记录]`、`[回单记录]`。

## 拜访记录（每次拜访）

| 字段 | 类型 | 说明 |
|---|---|---|
| 客户名称 | text | |
| 拜访日期 | datetime | 自动=今天 |
| 执行日期 | datetime | 自动=今天 |
| 拜访业务员 | text | 自动=录入人 |
| 接触方式 | select | 实地拜访 / 电话回访 / 微信沟通 / 其他 |
| 本次目的 | select | 新客户开发 / 客情维护 / 新品推广 / 订单跟进 / 售后回访 / 货款催收 / 其他 |
| 本次结果 | select | 已成交 / 有意向 / 持续跟进 / 暂无需求 / 其他 / 明确拒绝 |
| 核实到的需求 / 决策人 | text | 语音"本次对接了什么"归一到此 |
| 下一步具体动作 | text | 语音"具体动作与方案"归一到此 |
| 证据 / 需协助 | text | |
| 关注品类 | text | |
| 现用品牌 / 产品 | text | |
| 关联客户 | link | → 客户名单，按客户名称匹配后写 record_id |
| 今日拜访标记 | formula | 只读，不写 |

> 注意：拜访记录表**没有**「下次跟进日期」字段；下次跟进日期写入**客户名单.下次跟进日期**。

## 回单记录（每笔订单，含首单与回单）

| 字段 | 类型 | 说明 |
|---|---|---|
| 订单日期 | datetime | 订单详情回传的日期 |
| 客户名称 | text | 主字段 |
| 产品 | text | 炬森产品，按产品词库归一（升降机/衣帽间五金/拉篮/水槽/铰链/滑轨/反弹器等） |
| 数量 | number | |
| 单价（元） | number | |
| 总金额（元） | number | 从订单详情识别写入（实际成交金额，可能不等于数量×单价） |
| 业务员 | text | Excel 有业务员列直接用；没有则按客户名单「负责业务员」匹配 |
| 凭证 / 备注 | text | 订单号、备注等 |
| 关联客户 | link → 客户名单 | 按客户名称匹配后写 record_id |

> 说明：本表记录**每一笔订单**（不只首单）；每周数据可直接导入（Excel/表格/图片），由代理逐行识别写入：订单日期→日期、客户名→匹配客户名单、产品→词库归一、数量/单价/总金额→数字回读复核、业务员→Excel列或按客户名单匹配。

## 录入映射（语音 → 字段）

| 用户说的 | 落到哪个表哪个字段 |
|---|---|
| 客户名称 | 客户名单.客户名称；已存在→挂关联；不存在→先建档 |
| 新开发 / 老客户 | 客户名单.客户性质 = 新开客户 / 存量客户 |
| 开发阶段自动 | 新开客户→初步接触；存量客户→持续补货（如有采购） |
| 客户类型（默认轻高定） | 客户名单.客户类型 |
| 老板 | 客户名单.联系人 / 职务 |
| 门店几楼 / 地址 | 客户名单.区县 + 详细地址 |
| 电话 | 客户名单.联系电话 |
| 本次对接内容 | 拜访记录.核实到的需求 / 决策人 |
| 卡点问题 | 客户名单.当前卡点 / 需协助 |
| 具体动作与方案 | 拜访记录.下一步具体动作 |
| 下次跟进日期 | 客户名单.下次跟进日期 |
| 竞品 | 竞品信息收集（品牌/型号/价格/采购量） |
| 回单/订单 | 回单记录（订单日期/产品/数量/单价/总金额） |
| 上样照片 | 上样登记表（4 照片字段 + 上样日期=水印时间） |

## 只读字段（不写）

auto_number（序号）、formula（今日拜访标记、有效新增日期）、created_at / updated_at、link 反向字段。
