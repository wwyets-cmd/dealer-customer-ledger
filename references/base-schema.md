# 多维表格结构（Base Schema）

> 本文档描述代理商客户拜访与开发台账的 5 张表结构与录入映射。**字段名、select 选项以本文档为准**；写入前仍建议先 `+table-list` / `+field-list` 回读真实表 id 和字段名，禁止猜字段。

## 客户名单（客户主档）

| 字段 | 类型 | 说明 |
|---|---|---|
| 客户名称 | text | 主字段 |
| 客户性质 | select | 新开客户 / 存量客户（语音"新开发/老客户"归一到此）；描述客户当前状态 |
| 是否新开拓 | checkbox | **新开拓客户由业务员自行勾选，是看板"新开发"统计的唯一口径**。录入新客户（客户性质=新开客户、或业务员明确说"新开发/新开拓"）时勾选=true 并同步填「新开拓日期」；**一次勾选永久保留，不得因后续上样、首单、阶段流转到"持续补货"或客户性质改存量而取消勾选**。存量老客户不勾 |
| 新开拓日期 | datetime | 勾选「是否新开拓」时填写，默认=首次标记当天（录入日）；格式 `yyyy-MM-dd`。看板"今日/本月新开发"按本日期过滤 |
| 客户类型 | select | 轻高定 / 设计工作室 / 普定门店 / 前店后厂 / 普定工厂 / 代工厂（板材）。**必填，现场判定，判定定义与区分标准见 entry-template.md「客户类型判定」**，判断不出当场问、不替客户默认 |
| 联系人 / 职务 | text | 语音"老板"归一到此 |
| 联系电话 | text | |
| 区县 | text | |
| 详细地址 | text | 语音"门店几楼/工厂地址"归一到此 |
| 开发阶段 | select | **全自动流转，业务员不手选**。代理在每次写入拜访/上样/回单（含每周订单导入）后，按下面规则重算该客户阶段并 update 回本字段。阶段顺序：初步接触 / 已明确需求 / 上样待确认 / 上样待首单 / 首单已确定 / 持续补货；终止态：明确拒绝。**触发条件（从高到低判，命中最高阶段）**：①回单记录≥2笔→持续补货；②回单记录=1笔→首单已确定；③上样登记表有该客户记录→上样待首单；④话术中提到在谈上样/方案/报价但尚无上样登记→上样待确认；⑤「意向产品/需求」非空→已明确需求；⑥新建客户/以上都不满足→初步接触。**最近一次拜访结果=明确拒绝、且其后无上样/回单→明确拒绝**（终止）；一旦再出现上样或回单，自动复活并推进到对应阶段。**只进不退**：重算结果取「现有阶段」与「新推断阶段」的较高者，普通回访不得把阶段往回拉（明确拒绝→复活除外） |
| 负责业务员 | text | **默认首建人固定，可手动转交**：新建客户=录入人（首建人）；之后其他业务员再拜访，本字段**保持首建人不变**（拜访记录.拜访业务员始终记实际拜访人）；仅当使用者明确说"把 XX 客户转给 XX"时才更新本字段并回读确认 |
| 现用产品 | text | 客户目前主要用的产品 |
| 品牌 | text | 客户目前在用的品牌 |
| 合作供应商（竞争对手） | text | 客户目前合作的供应商/竞对 |
| 意向产品/需求 | text | 语音"意向产品、需求"归一到此 |
| 是否上样 | formula | 联动上样登记表：有上样记录=是，否则=否（只读，不写） |
| 上样超期标记 | formula | **上样→首单转化周期＝30 天（用户确认 A）**：已上样且回单 0 笔且首次上样（上样登记.上样日期最早值）距今 >30 天→"超期未首单"，否则空。表达式 `IF(AND(COUNTA([上样登记])>0, COUNTA([回单明细])=0, IFERROR(DATEDIF(MIN([上样登记].[上样日期]), TODAY(), "D")>30, FALSE())), "超期未首单", "")`（只读，不写） |
| 整体回单金额 | formula | 联动回单记录：按客户统计全部订单总金额合计（只读，不写） |
| 客户拜访次数 | formula | 联动拜访明细：该客户关联的拜访记录条数（只读，不写） |
| 拜访频率（次/月） | formula | 总拜访次数 ÷ 首次拜访至今的自然月数（含首月），保留1位小数（只读，不写） |
| 最近拜访日期 | formula | 联动拜访明细：=最近一次拜访的日期 MAX([拜访明细].[拜访日期])；无拜访=空（只读，不写） |
| 当前卡点 / 需协助 | text | 语音"卡点问题"归一到此 |
| 下次跟进日期 | datetime | 语音"下次跟进日期"归一到此（注意：不在拜访记录表）。**业务员说了具体日期→以说的为准；没说→按本次重算后的开发阶段自动填默认间隔（录入日 +N 天，可被业务员改）**：初步接触=3天；已明确需求/上样待确认/上样待首单=7天；首单已确定/持续补货=10天；明确拒绝=不设跟进（留空）。用于看板「今日待跟进/逾期待跟进」清单 |
| 回单明细 / 拜访明细 / 竞品信息 / 上样登记 | link | 反向关联字段，固定排在表格**最后四列**（只读侧，不写）。**注意命名：反向 link 字段名不得与目标表同名**——拜访记录/回单记录两张表的反向字段特意命名为「拜访明细」「回单明细」，否则公式里 `[拜访记录]` 会被解析成"整张表"而非"本列关联"，导致 COUNTA/SUM 统计为空 |

> 公式引用口径：客户名单所有联动统计均通过反向 link 字段（拜访明细/回单明细/上样登记）取值，如 `COUNTA([拜访明细])`、`MAX([拜访明细].[拜访日期])`、`SUM([回单明细].[总金额（元）])`；禁止在公式里写与表同名的 `[拜访记录]`、`[回单记录]`。

## 拜访记录（每次拜访）

| 字段 | 类型 | 说明 |
|---|---|---|
| 客户名称 | text | |
| 拜访日期 | datetime | 自动=今天 |
| 执行日期 | datetime | 自动=今天 |
| 拜访业务员 | text | 自动=录入人 |
| 接触方式 | select | 实地拜访 / 电话回访 / 微信沟通 / 其他 |
| 本次目的 | select | 新客户开发 / 客情维护 / 新品推广 / 订单跟进 / 售后回访 / 货款催收 / 其他 |
| 本次结果 | select | 已成交 / 有意向 / 持续跟进 / 暂无需求 / 其他 / 明确拒绝 |
| 核实到的需求 / 决策人 | text | 语音"本次对接了什么"归一到此 |
| 下一步具体动作 | text | 语音"具体动作与方案"归一到此 |
| 证据 / 需协助 | text | |
| 关注品类 | text | |
| 现用品牌 / 产品 | text | |
| 关联客户 | link | → 客户名单，按客户名称匹配后写 record_id |
| 今日拜访标记 | formula | 只读，不写 |

> 注意：拜访记录表**没有**「下次跟进日期」字段；下次跟进日期写入**客户名单.下次跟进日期**。

## 回单记录（每笔订单，含首单与回单）

| 字段 | 类型 | 说明 |
|---|---|---|
| 订单日期 | datetime | 订单详情回传的日期 |
| 客户名称 | text | 主字段 |
| 产品 | text | 成品五金按产品词库归一（升降机/衣帽间五金/拉篮/水槽/水龙头/柜体照明/开门器/铰链/滑轨/反弹器等）。**辅料/物料（螺丝、连接件、堵头、垫片、胶、封边条等）不单独分类、不建辅料词库、不另建表——产品名照录业务员/订单原话，保留具体名称，不强行归并到五金品类（用户确认 A）** |
| 数量 | number | |
| 单价（元） | number | |
| 总金额（元） | number | 从订单详情识别写入（实际成交金额，可能不等于数量×单价） |
| 业务员 | text | Excel 有业务员列直接用；没有则按客户名单「负责业务员」匹配 |
| 凭证 / 备注 | text | 订单号、备注等 |
| 关联客户 | link → 客户名单 | 按客户名称匹配后写 record_id |

> 说明：本表记录**每一笔订单**（不只首单）；每周数据可直接导入（Excel/表格/图片），由代理逐行识别写入：订单日期→日期、客户名→匹配客户名单、产品→词库归一、数量/单价/总金额→数字回读复核、业务员→Excel列或按客户名单匹配。

## 竞品信息收集

| 字段 | 类型 |
|---|---|
| 客户名称 | text |
| 竞品品牌 | select（单选） | 预置主流竞品：悍高/东泰/卡贝/图特/汇泰龙/高乐高/百隆/海蒂诗/格拉斯/海福乐/萨里奇/顶固。**清单外新品牌业务员口述即直接新增为选项、无需二次确认**；近似/同音发音先按 vocab-errors.md 品牌别名表自动归并到规范名（如 Higold/汉高→悍高、DTC/帝腾→东泰、Blum→百隆），归并不了的全新品牌才新增 |
| 竞品型号 | text |
| 价格 | number |
| 客户采购量 | number |
| 关联客户 | link → 客户名单 |

> **竞品口径＝只记录、不比价（用户确认 A）**：照实录入业务员现场听到的竞品品牌、型号、价格、客户采购量即可。「价格」就是业务员听到的单价，**不区分口头报价/实际成交价，不与我方炬森价格做对比、不自动带我方价、不算差价**；系统不建任何比价/差价字段。价格、采购量为数字，录入前逐项回读复核。一条竞品录一行；同客户多个竞品分别录多行。

## 上样登记表

| 字段 | 类型 | 说明 |
|---|---|---|
| 公司名称 | text | 主字段 |
| 序号 | auto_number | 自动 NO.001…（只读） |
| 门店 / 工厂 | text | 注意字段名含空格：`门店 / 工厂` |
| 联系人 | text | |
| 电话 | text | |
| 地址 | text | |
| 门头签单合照 | attachment | **必传**，须水印相机拍摄（带时间、地点水印）；证明签约门店 |
| 协议合照 | attachment | 选传（有则传），建议水印 |
| 上样前照片 | attachment | 选传（有则传），建议水印 |
| 上样后照片 | attachment | **必传**，须水印相机拍摄（带时间、地点水印）；证明上样完成 |
| 备注上样产品 | text | 上样了哪些产品 |
| 上样日期 | datetime | **取必传照片（门头签单合照/上样后照片）的水印相机时间**，不默认今天；水印看不清先问 |
| 关联客户 | link → 客户名单 | 老客户自动挂，新客户先建档 |

> **上样核销硬性校验（用户确认 B）**：登记一条上样记录，**门头签单合照、上样后照片两张必传且须为水印相机照片**，缺任一张必须当场向使用者追问补齐才提交，不用占位/不编造；协议合照、上样前照片有就归档、没有不阻断。**同一客户、同一时间段发的多张照片合并为同一条上样记录**，按内容分别归到四个照片字段，不重复建档。**上样→首单转化周期＝30 天（用户确认 A）**：上样后 30 天内出首单为正常，超 30 天客户名单「上样超期标记」自动标"超期未首单"，由看板「上样超期未首单(>30天)」清单列出，督促业务员跟进动销。

## 录入映射（语音 → 字段）

| 用户说的 | 落到哪个表哪个字段 |
|---|---|
| 客户名称 | 客户名单.客户名称；已存在→挂关联；不存在→先建档 |
| 新开发 / 老客户 | 客户名单.客户性质 = 新开客户 / 存量客户 |
| 开发阶段自动 | 新开客户→初步接触；存量客户→持续补货（如有采购） |
| 客户类型（默认轻高定） | 客户名单.客户类型 |
| 老板 | 客户名单.联系人 / 职务 |
| 门店几楼 / 地址 | 客户名单.区县 + 详细地址 |
| 电话 | 客户名单.联系电话 |
| 本次对接内容 | 拜访记录.核实到的需求 / 决策人 |
| 卡点问题 | 客户名单.当前卡点 / 需协助 |
| 具体动作与方案 | 拜访记录.下一步具体动作 |
| 下次跟进日期 | 客户名单.下次跟进日期 |
| 竞品 | 竞品信息收集（品牌/型号/价格/采购量） |
| 回单/订单 | 回单记录（订单日期/产品/数量/单价/总金额） |
| 上样照片 | 上样登记表（4 照片字段 + 上样日期=水印时间） |

## 只读字段（不写）

auto_number（序号）、formula（今日拜访标记、有效新增日期）、created_at / updated_at、link 反向字段。
