# 语音录入模板（Entry Template）

> 使用者把信息说得越详细越好；一次语音可以同时录多个板块（客户/拜访/竞品/采购/上样），代理自动拆分写入对应表。其余信息由代理自动补全。

## 各板块可说的详细信息

**客户板块**：客户名称；新开发还是老客户；客户类型（默认轻高定，也可是设计工作室/普定门店/前店后厂/普定工厂/代工厂）；老板/联系人姓名；门店在哪个商场几楼或工厂地址；区县；电话；主要做什么产品。

**拜访板块**：拜访的客户名称；本次目的（新客户开发/客情维护/新品推广/订单跟进/货款催收）；本次结果（已成交/有意向/持续跟进/暂无需求/明确拒绝）；主要对接了什么内容；下次需要做什么；下次跟进日期；电话/微信等方式。

**竞品板块**：哪个客户处收集的；竞品品牌或产品名；型号；价格；客户采购量；和咱们产品的对比（如有）。

**采购板块**：客户名称；哪个月；销售额；退货额（如有）。

**上样板块**：公司/门店名称；上样了什么产品；直接发照片（自动识别水印时间登记日期、按内容归档到对应照片字段）。

## 自动补全清单（使用者不用报）

| 项 | 默认值 |
|---|---|
| 拜访日期 | 今天 |
| 业务员/负责业务员 | 安装时确认的录入人姓名 |
| 客户性质关联的开发阶段 | 新开发→待接触；老客户→持续补货 |
| 上样日期 | 照片水印相机时间 |
| 关联客户 | 按客户名称自动挂 |
| 序号 | 自动编号 |

## 建议必报（缺失会影响业务闭环）

1. 下次跟进日期（×月×日）——没有它回访跟踪会断
2. 本次结果（已成交/有意向/持续跟进/暂无需求/明确拒绝）——决定下一步怎么安排
3. 联系电话（建档必需，语音易错，可先说"后补"）

## 口语示例（一段话录多表）

> "录一下今天拜访的：济南华鑫全屋定制，老客户，客户是轻高定，老板姓王，门店在历城工业北路88号，电话后补。今天主要对接了升降机 SL-A 的上样和柜体照明方案，客户挺有意向，说要对比下价格，下次6月25号之前我带样品过去再跟进报价。竞品也收集了一条：悍高 HIG-560 那个型号，210块钱，华鑫采购量500套。"

拆解结果：
- 客户名单：华鑫全屋定制（老客户→持续补货，轻高定，王老板，历城工业北路88号）
- 拜访记录：拜访日期=今天，目的=新品推广/订单跟进，结果=有意向，对接内容=升降机SL-A上样+柜体照明方案，下次动作=带样品跟进报价，下次跟进日期=6月25日
- 竞品信息收集：华鑫，悍高 HIG-560，¥210，采购量500

## 录入回执

每次录入完成后，代理应向使用者回读：
- 新建/更新了哪几张表、哪几条记录
- 客户关联是否正确
- 上样照片归档到哪个字段、上样日期取的水印时间
- 若有关键字段存疑（电话、地名、型号），当场复述让使用者确认
