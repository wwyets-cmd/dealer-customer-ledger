# 语音录入模板（Entry Template）

> 使用者只需报核心信息，其余由代理自动补全。模板设计目标是"极简、语音友好"。

## 极简模板（使用者只需说这些）

```
录客户：客户名称；新开发或老客户；客户类型（默认轻高定）；老板：××；门店：××商场几楼
录拜访：本次主要对接了什么；下次需要做什么；下次跟进日期
录竞品：竞品品牌或产品；型号；价格；采购量
录上样：公司名称；门店；上样产品 + 发照片
录采购：客户名称；月份；销售额；退货额（如有）
```

一次可只报一个板块（如只说"录竞品：悍高 560 210块 采购500"），也可一次报多个板块（一条消息录多个表）。

## 自动补全清单（使用者不用报）

| 项 | 默认值 |
|---|---|
| 拜访日期 | 今天 |
| 业务员/负责业务员 | 安装时确认的录入人姓名 |
| 客户性质关联的开发阶段 | 新开发→待接触；老客户→持续补货 |
| 上样日期 | 照片水印相机时间 |
| 关联客户 | 按客户名称自动挂 |
| 序号 | 自动编号 |

## 建议必报（缺失会影响业务闭环）

1. 下次跟进日期（×月×日）——没有它回访跟踪会断
2. 本次结果（已成交/有意向/持续跟进/暂无需求）——决定下一步安排
3. 联系电话（建档必需，语音易错，可先说"后补"）

## 录入回执

每次录入完成后，代理应向使用者回读：
- 新建/更新了哪几张表、哪几条记录
- 客户关联是否正确
- 上样照片归档到哪个字段、上样日期取的水印时间
- 若有关键字段存疑（电话、地名、型号），当场复述让使用者确认
