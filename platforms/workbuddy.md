# WorkBuddy（OpenClaw）安装与连接

适用：**WorkBuddy / OpenClaw** 等带"技能 + 连接器"机制的客户端。本平台的飞书连接方式为 **飞书 MCP 连接器**（feishu-connection.md 中的方式 B）。共 4 步，约 5 分钟。

## 第 1 步：安装技能

1. 取得本技能压缩包（`dealer-customer-ledger-universal`）并解压。
2. 把整个 `dealer-customer-ledger-universal` 文件夹放入客户端技能目录（默认形如 `~/.openclaw/workspace/skills/`），或在「专家·技能·连接器」→「技能」页用导入入口选择该文件夹。
   - 客户端读取其中的 **`SKILL.md`**；`references/`、`platforms/`、`AGENTS.md` 一并保留。
3. **新开一个对话**（或按客户端提示重载技能）。

## 第 2 步：配置飞书连接器（关键）

台账数据写在飞书多维表格里，必须先连接飞书。

1. 打开 WorkBuddy 左侧「**专家·技能·连接器**」→ 顶部选「**连接器**」页。
2. 找到「**飞书**」卡片（管理飞书/Lark：即时通讯、云文档、多维表格 Base 等），点右上角「**+**」。
3. 按弹出的指南完成授权，常见两种（以实际引导为准）：
   - **快捷授权**：扫码 / 登录飞书账号，勾选同意多维表格权限；
   - **应用凭证**：在飞书开放平台创建自建应用，拿 **App ID、App Secret** 回填，并在「权限管理」开通多维表格读写权限（至少含 `bitable:app` 及记录创建/读取/更新）。
4. 授权完成后飞书卡片显示已连接（绿点）。
5. 若为自建应用，记得把**应用（机器人）加为你台账副本的协作者、给「可编辑」**（否则连接器能连上但读不到这份表）。

> 权限务必开全，否则会出现"能读不能写"或无法新建记录。

## 第 3 步：复制自己的台账模板

每位代理商 / 每个门店复制一份自己的副本，不要在公共母版上录数据。

1. 用自己的飞书账号打开模板：`https://my.feishu.cn/base/FyKib8lh8aIqJxsHppUcVkDnnEb`
   （打不开/没权限，找管理员开「可编辑」或「可复制」权限）。
2. 点表格名旁「**⋯**」（手机端在右上角「⋯」，或在飞书云空间右键该文件）。
3. 选「**复制**」→ 选保存位置（建议"我的空间"）→ 命名，如 `客户台账-王磊`。
4. 打开副本确认含 **5 张表 + 看板**：客户名单、拜访记录、回单记录、竞品信息收集、上样登记表 + 信息汇总看板。

## 第 4 步：在对话里确认信息，开始录入

1. 告诉助手：**录入人/业务员正式全名**（如"我是王磊"）+ **你复制的副本链接**。
2. 助手通过连接器做连通自检 → 结构对账 → 建个人视图 → 回读确认后即可录入，例如：
   > "录一下今天拜访的：济南华鑫全屋定制，老客户，轻高定……"
3. 每次录入后助手会：回写各表 → 回读核对 → 生成一段可直接发工作群的汇报文案。

## 常见问题

- **连接器里找不到飞书**：更新客户端到最新版；或用「自定义连接器」按飞书官方 MCP 指南添加（feishu-connection.md 方式 B/C）。
- **提示无权限/写入失败**：回第 2 步检查多维表格权限是否开全、应用是否已加为副本协作者、你本人对副本是否「可编辑」。
- **连接器没有"建字段/看板"工具**：结构对账中这部分由助手列清单，你在飞书界面按 base-schema.md 手动补即可。
- **技能没出现**：确认文件夹含 `SKILL.md` 且放在正确技能目录，新开会话重载。
