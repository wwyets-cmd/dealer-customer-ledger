# 豆包工作（Doubao）安装与连接

适用：豆包工作 / 豆包办公等**内置 lark-cli 沙箱**的环境。本平台的飞书连接方式为 **lark-cli**（feishu-connection.md 中的方式 A）。

## 一、安装技能

1. 把整个 `dealer-customer-ledger-universal` 文件夹放入豆包技能目录（或通过技能导入入口选择该文件夹）。
2. 豆包识别根目录的 **`SKILL.md`**（YAML frontmatter 提供名称与触发描述）；`references/`、`platforms/` 按需加载。
3. **新开一个对话**，让技能被加载。

## 二、飞书连接：lark-cli（默认已具备）

- 豆包沙箱内置 lark-cli，配合 `lark-base` / `lark-drive` 技能，按**用户本人授权**（`--as user`）读写多维表格。
- 首次确认 Base 后先自检（把 `/base/` 后那段作为 base-token）：
  ```bash
  lark-cli base +table-list --base-token <app_token>
  ```
  能列出 5 张表即连通。

## 三、常用命令（完整对照见 references/feishu-connection.md）

| 操作 | 命令 |
|---|---|
| 查表 / 字段 | `lark-cli base +table-list` / `+field-list --table-id <id>` |
| 查记录（查重） | `lark-cli base +record-list --table-id <id>`（可配合筛选/搜索） |
| 批量新建 | `lark-cli base +record-batch-create`（`create_records` 为字段 map 数组） |
| 更新 | `lark-cli base +record-batch-update`（`update_records` 为 `{record_id:{字段:值}}`） |
| 删除多余空记录 | `lark-cli base +record-delete` |
| 上传上样照片 | `lark-cli base +record-upload-attachment --field-id <id> --file <path>` |
| 建视图 / 字段 / 看板 | `lark-cli base +view-create` / `+field-create` / `+dashboard-block-create` |

- 日期字段传 `YYYY-MM-DD HH:mm:ss`；单选传选项名字符串；多选传数组；link 传 `[{"id":"<record_id>"}]`；勾选传 true/false。
- 建公式字段、改字段类型等按 lark-base 技能要求带确认 flag（`--i-have-read-guide`、`--yes`）。
- 结构创建串行、间隔 2–3 秒防限流；**写后必须 `+record-list` 回读**，禁止仅凭写成功宣称完成。

## 四、首次对话

告诉助手：**录入人正式全名** + **你复制的台账副本链接**。助手会：连通自检 → 结构对账 → 建个人视图 → 展示录入模板，然后开始语音录入。

## 常见问题

- **写入失败/无权限**：确认你本人对副本是「可编辑」协作者（permission-guide.md）。
- **找不到命令**：确认沙箱已加载 lark-base 技能；新开会话重试。
- **公式/看板建不了**：个别能力受限的，按助手回执里列出的清单在飞书界面手动补建。
