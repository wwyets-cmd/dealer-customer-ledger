# 代理商客户拜访与开发台账技能（dealer-customer-ledger）

语音 / 文字录入客户拜访信息，自动拆解并写入飞书多维表格，5 表联动 + 数据看板：

- **客户名单**（一人一档，统计主表）
- **拜访记录**（每次拜访一条）
- **回单记录**（每笔订单，不只首单）
- **竞品信息收集**（品牌 / 型号 / 价格 / 采购量）
- **上样登记表**（水印相机照片，日期按水印时间）
- **信息汇总看板**（拜访量、新开发、业绩排名、竞品分析等）

## 两个平台版本（按你用的工具选择）

| 平台 | 技能位置 | 飞书读写方式 |
| --- | --- | --- |
| **豆包 / Doubao** | 仓库根目录（`./SKILL.md` + `./references`） | `lark-cli`（lark-base 技能） |
| **WorkBuddy / OpenClaw** | **`./workbuddy/dealer-customer-ledger/`** | WorkBuddy「飞书」连接器（MCP） |

> 两个版本的业务规则完全一致（一人一档、字段映射、口音纠错、上样水印、工作群汇报、每周 Excel 导入），仅工具调用层不同。

## 快速开始

1. 按平台复制对应技能文件夹到技能目录（WorkBuddy 版见 `workbuddy/dealer-customer-ledger/references/install-workbuddy.md`）。
2. 复制飞书台账模板，得到自己的副本：
   **https://my.feishu.cn/base/FyKib8lh8aIqJxsHppUcVkDnnEb**
3. 在对话里报录入人姓名 + 台账副本链接，开始语音录入。

## 口语录入示例

> 录一下今天拜访的：济南华鑫全屋定制，老客户，轻高定，老板姓王，门店在历城工业北路88号，电话18888888888。今天对接升降机SL-A上样，客户有意向，但担心承重、且xx品牌HIG-560只报1200，我们没价格优势。下次10月25日前上门，带样板演示承重、出照明报价。竞品一条：xx HIG-560，1200，上月采购了5套。

录入核对后会自动生成一段可直接发工作群的汇报文案。

## 每周订单导入

每周把销售明细（Excel/CSV/截图，含订单日期、客户名、产品、数量、单价、总金额）发来，自动识别写入回单记录，见 `references/import-guide.md`。
